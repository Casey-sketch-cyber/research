D3 (parametric compact shells) is generated by `scripts/03_build_corpus.py` and needs no download.

`scripts/01_download.py` writes `data/raw/MANIFEST.csv` with SHA-256 checksums. If the code runs somewhere without internet, download these files by hand to the paths above and run `python scripts/01_download.py --verify-only`.

## Acquisition and inspection implemented

Concrete URLs and the D2 revision are fixed in `config/downloads.yaml`. D1 is also checked against the publisher's MD5; every completed archive receives a SHA-256 digest. Only ABO listing metadata are fetched.

```sh
python scripts/01_download.py --config config/project.yaml
python scripts/01_download.py --config config/project.yaml --verify-only
python scripts/02_inspect_schemas.py --config config/project.yaml
```

`--datasets` can select an explicit subset during staged transfers. Partial reports are marked as such. The publication copy of the manifest is `reports/data_manifest.csv`; it contains public source URLs and relative filenames only. Geometry extraction is limited to required members, verifies archive CRCs, and never extracts source locations or location ratings.

The pinned ResPlan pickle is read with a restricted constructor allowlist. Its polygon coordinates must not be interpreted as metres without calibration. The released `net_area` field is not trusted as a metric calibration target; see the full scale audit and the explicit assumption proposed for G1 in `reports/schemas/D2.md`.

The D6 CSV has bilingual descriptive headers followed by machine-readable field names. It supplies aggregate counts but does not supply household-size or dwelling-area distributions. The general IDDS PDF is inspected separately; source-specific field meanings are taken from the official CSV, not invented.
