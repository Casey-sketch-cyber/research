# Data

`raw/` and `interim/` are git-ignored. Only small derived tables in `processed/` may be committed (each file < 50 MB).

| ID | Dataset | Where to get it | Save as |
|---|---|---|---|
| D1 | Swiss Dwellings v3.0.0 (CC BY 4.0) | https://zenodo.org/records/7788422 → `swiss-dwellings-v3.0.0.zip` (~0.93 GB) | `data/raw/swiss_dwellings/swiss-dwellings-v3.0.0.zip` |
| D2 | ResPlan (CC BY 4.0) | https://github.com/m-agour/ResPlan (`ResPlan.zip`) or https://www.kaggle.com/datasets/resplan/resplan | `data/raw/resplan/` |
| D4 | ABO listings only (CC BY 4.0) | https://amazon-berkeley-objects.s3.amazonaws.com/index.html → `abo-listings.tar` (83 MB) | `data/raw/abo/abo-listings.tar` |
| D5 | ATUS microdata (optional) | https://www.bls.gov/tus/data.htm | `data/raw/atus/` |
| D6 | HK 2021 Census, subdivided units by DC district | https://data.gov.hk/en-data/dataset/hk-censtatd-census_geo-2021-population-census-su-by-dcd (CSV/XLSX and data dictionary) | `data/raw/hk_census/` |

D3 (parametric compact shells) is generated by `scripts/03_build_corpus.py` and needs no download.

`scripts/01_download.py` writes `data/raw/MANIFEST.csv` with SHA-256 checksums. If the code runs somewhere without internet, download these files by hand to the paths above and run `python scripts/01_download.py --verify-only`.
