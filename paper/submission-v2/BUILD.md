# Rebuild the iScience v2 package

Run the scripts from the repository root with task-local temporary directories. The reviewed manuscript and the committed plot inputs are the data sources.

- Main LaTeX and PDF: run `python scripts/14_submission_latex.py --pandoc PANDOC --tectonic TECTONIC --template TEMPLATE_ZIP --out UPLOAD --work-dir SCRATCH`. Use the [Cell Press LaTeX v1.10 archive](https://www.cell.com/pb-assets/journals/platform/authour-resources/cell-press-latex-template-1747231785383.zip) as TEMPLATE_ZIP. The release is dated 13 May 2025 and has SHA-256 `d5fea9a7718bd857ae5e71753eed4a7dfc62303992656775ee15d5b2068b5dfe`. This archive is needed to regenerate the TeX source from Markdown.
- To compile the delivered LaTeX source, run `tectonic Manuscript.tex` in upload with Manuscript.bbl, references.bib, numbered.bst and numcompress.sty present. Tectonic 0.17.0 and Pandoc 3.14 produced the package. The main source uses TeX Gyre Heros for the template's Helvetica-style text under XeTeX. BibTeX uses the publisher's numbered style, with the approved bibliography in first-citation order.
- Plot plates and main figure exports: run `python scripts/14_submission_figures.py --out UPLOAD --supplement-dir PLATES --skip-ga` with the repository plotting dependencies (including the editable fea package) and PDF/TIFF dependencies. The plotter reads the committed results and uses a submission-specific layout profile.
- Supplement: run `python scripts/14_submission_supplement.py --repo . --output UPLOAD/SupplementalInformation.pdf --pandoc PANDOC --work-dir SCRATCH --figure-dir PLATES`. This uses Chromium and the regenerated plates.
- Highlights and Key Resources Table: run `python scripts/14_submission_attachments.py --repo . --output UPLOAD --pandoc PANDOC --work-dir SCRATCH`. For Table S4, run `node scripts/14_submission_table_s4.mjs SCRATCH/TableS4-input.json UPLOAD/TableS4.xlsx` with @oai/artifact-tool available. The cover letter is the approved Word conversion preserved in v1 because its source did not change.
- The separately editable 4-inch graphical abstract is in paper/figures/fig1/GraphicalAbstract_4in.pptx. Export its slide as a vector PDF and render to RGB TIFF at 300 dpi with LZW compression. The 5.5-inch authoring version is GraphicalAbstract.pptx in the same directory.
- The reading copy with the figures appended uses make_manuscript from scripts/13_submission_word.py with the final figures directory and mark_funding=False. Its PDF is a reading copy generated by Word.

To rebuild the LaTeX reading copy, first generate the six main figure PDFs in upload. From the package root, run `tectonic Manuscript_LaTeX_with_figures.tex --outdir review`. The wrapper loads the same main TeX file and appends one page per main figure. Alternatively, pass `--review-dir REVIEW` when rebuilding the main TeX. UPLOAD and REVIEW must be sibling directories, with UPLOAD named upload.

The review and author directories are for author checks. Use the upload directory for selecting journal files after completing the separate author steps. Choose one format per artwork item as required by the portal.
